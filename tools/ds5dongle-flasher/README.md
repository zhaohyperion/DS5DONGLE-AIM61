# DS5Dongle Windows Flasher

Single-file Windows GUI and CLI flasher for DS5DONGLE-AIM61. It prefers stable AI-M61 Full-Speed firmware while remaining compatible with other complete packages produced by this repository. It reads the running firmware version over USB HID and supports GitHub Release downloads, local ZIPs/directories, SHA256 verification, COM-port discovery, BOOT+RESET guidance, and 460800/115200 baud retry.

See [`../../docs/FLASHER.md`](../../docs/FLASHER.md) for package, build, and release instructions.
