# DS5Dongle Windows Flasher

Single-file Windows GUI and CLI flasher for AI-M61-32S-KIT, LCTech BL616, and Sipeed M0S Dock. It prefers stable AI-M61 Full-Speed firmware by default while retaining explicit selection of every board and speed. It supports GitHub Release downloads, local ZIPs/directories, SHA256 verification, COM-port discovery, BOOT+RESET guidance, and 460800/115200 baud retry.

See [`../../docs/FLASHER.md`](../../docs/FLASHER.md) for package, build, and release instructions.
