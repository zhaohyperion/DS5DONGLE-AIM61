# DS5Dongle Windows 一键刷写器

面向 AI-M61-32S-KIT、LCTech BL616 和 Sipeed M0S Dock 的单文件 Windows GUI/CLI 刷写器。默认首选稳定版 AI-M61 Full-Speed 固件，同时保留所有板型和速度的显式选择；支持 GitHub Release 在线下载、本地 ZIP/目录、SHA256 校验、COM 口检测、BOOT+RESET 引导，以及 460800/115200 波特率失败重试。

固件包格式、构建和发布方法见 [`../../docs/FLASHER.md`](../../docs/FLASHER.md)。
